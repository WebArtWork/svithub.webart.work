## About
SvitHub — хостел (`hostel`) у Кам’янці-Подільському, вул. Лесі Українки, 79А. Сторінка продає SOCIAL STAY + CITY BASE + ACTIVE TRAVEL за формулою STAY · MEET · EXPLORE, а не «дешеве ліжко». «Hub» не трактується як коворкінг, івенти чи організована спільнота; соціальний досвід не гарантується.
